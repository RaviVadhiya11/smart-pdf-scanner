SMART PDF SCANNER – PWA STARTER

Files:
- index.html: scanner prototype
- manifest.webmanifest: installable web app metadata
- sw.js: basic offline caching for app shell
- icons/: app icons

IMPORTANT:
This is a prototype/PWA starter, not a finished Play Store app.
It currently supports camera/gallery image selection and multi-page PDF creation.
It does not yet include automatic edge detection, advanced crop/filters, password-protected PDF,
or a full native Android implementation.
